# Restaurant Review API

This project is a **Restaurant Review API** built with **Flask**.  
It manages restaurants and reviews with JWT auth, caching, 
request rate limiting, provides basic analytics and optional async endpoint.

## Features
1. Restaurant Management
2. Review Management
3. Basic Analytics (average rating, top 3 restaurants by cuisine)
4. PostgreSQL using SQLAlchemy 
5. JWT Authentication 
6. Role-based access 
7. Rate limiting 
8. Caching with Flask-Caching 
9. Docker support 
10. Basic AsyncIO demonstration
